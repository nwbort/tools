P2P File Transfer

How it works: files go straight from one browser to the other over your network. They are never uploaded anywhere. The only thing that touches a server is a short code used to introduce the two browsers to each other, and that lives in memory for a few minutes and is then thrown away.

  1. On one device, click Create a connection.
  2. On the other, scan the QR code or type the eight-character code.
  3. Once connected, either side can send files.

Both devices need to be on the same network. There is no relay and no external server, so a transfer never leaves your network.
